איך מעלים את האפליקציה ומתקינים בטלפון
1. העלו את כל הקבצים בתיקייה הזו לאחסון סטטי בחינם, למשל app.netlify.com/drop (גוררים את התיקייה) או GitHub Pages.
2. פתחו את הכתובת שקיבלתם בטלפון.
3. אנדרואיד (Chrome): תפריט ⋮ ← "התקנת אפליקציה" / "הוספה למסך הבית".
   אייפון (Safari): כפתור השיתוף ← "הוספה למסך הבית".
האפליקציה תיפתח במסך מלא, עם אייקון משלה, ותעבוד גם בלי אינטרנט.
